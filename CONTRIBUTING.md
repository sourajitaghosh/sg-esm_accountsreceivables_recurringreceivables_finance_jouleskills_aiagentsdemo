# Contributing

Thank you for your interest in contributing to this SAP Autonomous Finance Joule Skill.

## How to Contribute

### Reporting issues
Open a GitHub issue describing the problem or improvement suggestion.

### Improving the skill
1. Fork the repository
2. Create a branch: `git checkout -b feature/your-improvement`
3. Make your changes to the skill files under `skills/sap-autonomous-finance-esm-ar-rr-demo/`
4. Commit: `git commit -m "describe your change"`
5. Open a pull request

### Skill file locations
- `skills/sap-autonomous-finance-esm-ar-rr-demo/SKILL.md` — main skill (persona, activation, agent roster, rules)
- `skills/sap-autonomous-finance-esm-ar-rr-demo/references/demo-data.md` — all locked mock data
- `skills/sap-autonomous-finance-esm-ar-rr-demo/references/demo-script.md` — full scripted flow (29 acts)
- `skills/sap-autonomous-finance-esm-ar-rr-demo/references/demo-cheat-sheet.md` — presenter prompt guide
